# ATS Chatbot

Applicant Tracking System (ATS) Chatbot repository containing system documentation, requirements, architecture, API specifications, and evaluation guidelines.

## Project Structure

- `docs/01-product/`: Product vision, roadmap, and specifications
- `docs/02-requirments/`: Functional requirements and user stories
- `docs/03-architecture/`: System architecture design documents
- `docs/04-database/`: Database schema and indexing models
- `docs/05-Api/`: API specifications and contract details
- `docs/06-Ai/`: AI logic and integration patterns
- `docs/07-security/`: Security standards and compliance
- `docs/08-testing/`: Test plans and evaluation metrics
